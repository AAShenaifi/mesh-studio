# Mesh Studio and STL Studio

Mesh Studio absorbed every feature of the earlier STL Studio tool (text, drill,
resize, rotate and mirror, the OpenSCAD generators, weight and filament
estimate, edges overlay, measure) and added its own: cutting with connectors,
booleans, hollowing, repair, painting, STEP import, image and SVG import.
STL Studio is retired. This file used to hold the merge plan; the feature list
now lives in [README.md](./README.md) and the gaps in [GAP_ANALYSIS.md](./GAP_ANALYSIS.md).
